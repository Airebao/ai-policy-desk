# AI 政策台

查询 AITOP 政策台收录的 AI 法规、指引、标准、资助与监管沙盒：当前状态（征询中 / 已通过 / 已生效）、生效与征询截止日期、影响对象和应对动作。用于“欧盟 AI 法案什么时候生效”“哪些 AI 政策还在征询期”“越南、印尼有什么 AI 新规”“这条规定对模型提供方有什么影响”等合规与政策查询。监管新闻快讯请用 ai-funding。

## 文件

- `_meta.json` — 发布元数据（slug / version / displayName / summary / license / edition）
